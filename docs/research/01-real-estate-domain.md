# 不動産流通ドメイン・リファレンス（賃貸／売買）

> 2026-10-13 にサブエージェントが調べた結果をまとめたもの。法的な検討は対象外。
> Webで裏付けを確認したのは「レインズの登録期限」と「徒歩80m=1分」のルールだけで、それ以外は業界の通説・実務知識による。

## 1. 流通の仕組み

### 1.1 プレイヤー
| 役割 | 別名 | 内容 |
|---|---|---|
| 貸主・売主 | オーナー | 物件の所有者。賃貸では管理会社に任せていることが多い |
| **元付業者** | 媒介業者、物元、管理会社 | オーナーから媒介・管理を受けて募集する。広告可否・内見可否を決める |
| **客付業者** | 仲介業者 | 借主・買主を見つけて元付につなぐ。**Devote（ミカド）は基本的にこちら側** |
| 両手 / 片手 | — | 元付と客付が同じ会社なら両手（双方から手数料）、別の会社なら片手 |

### 1.2 媒介契約とレインズ登録義務（売買）
- **専属専任媒介**: 契約の翌日から **5日以内**（休業日を除く）に登録義務。業務報告は1週間に1回以上
- **専任媒介**: 翌日から **7日以内**（休業日を除く）に登録義務。業務報告は2週間に1回以上
- **一般媒介**: 登録は任意。複数の業者に同時に依頼できる
- **賃貸**: 法律上の登録義務はない。賃貸物件はレインズより、**業者間サイト（ATBB／ITANDI BB／いい生活スクエア 等）**や管理会社の業者向けページで流通する割合が高い

### 1.3 レインズ（REINS）
- 4つの指定流通機構が運営: 東日本（関東甲信越・北海道・東北）／中部圏／近畿圏／西日本
- **IP型（Web版）は宅建業者の会員だけが使える**。所属団体を通じて入会し、ID・パスワードが発行される
- 検索の流れ: 売買か賃貸かを選ぶ → 物件種別 → 所在地または沿線駅 → 価格・面積・間取り・築年 → 取引態様・取引状況（公開中／書面による購入申込みあり／売主都合で一時紹介停止中）。結果一覧から詳細へ進み、**図面PDF（マイソク）**を取得できる。物件番号は12桁
- 仕様変更やログイン障害が頻繁にあり、DOMに依存する実装は壊れやすい

### 1.4 図面（マイソク）・広告可否・AD
- **マイソク**: A4の物件概要と間取りの図面。下部の「帯」に元付業者・取引態様・手数料配分・**広告可否**が書かれている
- **広告可否**: 「広告可／広告不可／要確認／ネット可・紙不可」。広告不可でも紹介はできる
- **AD（広告料）**: 賃貸で元付やオーナーが客付業者に払う謝礼。**AD付きは「客付歓迎」のシグナル**

### 1.5 ポータル掲載フロー
1. 元付が登録する（レインズ、ATBB等の業者間サイト、自社の基幹システム）
2. 元付または客付が、広告可の物件を基幹システム（いい生活、ラクテック、いえらぶ 等）で入稿する
3. 入稿データが SUUMO／LIFULL HOME'S／at home 等へ連携される
4. 同じ物件を複数の客付業者が載せるので、**ポータル上で重複する**

### 1.6 囲い込み・自社サイトのみの掲載
- **囲い込み**: 両手取引を狙って、他社からの問い合わせを断ったりレインズで紹介停止にしたりする行為。Devoteでは「問い合わせたら紹介不可だった」という形で表に出る → 類似物件の提案につながる
- **自社サイトのみ・自社サイト先行で掲載する例**: 大東建託「いい部屋ネット」、積水ハウス「シャーメゾン」、大和リビング「D-room」、レオパレス21、旭化成「へーベルメゾン」、UR賃貸、JKK東京。売買では三井のリハウス、住友不動産販売、東急リバブル、野村の仲介+
- **おとり物件**: 成約済みなのにポータルに残っている物件

### 1.7 情報が出るまでのラグ（目安）
| ソース | 新着の反映 | 成約の反映 |
|---|---|---|
| 管理会社の業者向けサイト・自社サイト | 最速（即日） | 早い |
| レインズ | 売買の専任系は5〜7営業日以内。賃貸はまちまち | ステータス更新が遅れることがある |
| ポータル | 数時間〜数日 | 数日〜数週間遅れる（おとり物件の温床） |

## 2. 物件データ項目の正規化
| 項目 | 注意点 |
|---|---|
| 物件番号 | `source + source_id` の組で一意にする |
| 所在地 | 丁目の漢数字と算用数字の揺れ。normalize-japanese-addresses で正規化し、緯度経度を付ける |
| 交通 | **徒歩は道路距離80m=1分で、端数は切り上げ**。「バス10分 停歩3分」は徒歩と分けて持つ。駅名の揺れ（ヶ/ケ） |
| 間取り | 1R/1K/1DK/1LDK/2LDK+S。全角半角、「ワンルーム」「2LDK＋納戸」などの揺れ |
| 専有面積 | ㎡・m2・平米・m²を統一。坪表記もある。壁芯と内法で値に差が出る |
| 築年月 | 和暦（平成20年3月・H20.3）、「築16年」 → 西暦の年月に変換 |
| 構造 | RC / SRC / S / 軽量鉄骨 / 木造 |
| 階 | `所在階 / 地上階数`、地下、メゾネット |
| 設備 | 自由記述 → 辞書でタグにする（`packages/core/src/features.ts`） |
| 取引態様・広告可否・元付業者 | 客付できるかの判定に必須 |
| 賃料 | **賃料・管理費・総額を分けて持ち、総額で検索できるようにする** |
| 敷金・礼金 | 「1ヶ月」「10万円」「なし」。保証金・敷引き（関西） |
| 入居条件 | ペット・楽器・事務所利用・二人入居など。**hard条件になる** |

## 3. 同一物件の重複判定に使う特徴量
- ブロッキング: 町丁目（または geohash6）× 最寄駅 × 種別
- スコアの材料（重要度順）: 建物の特定（名前の正規化、所在地＋築年月＋構造＋総階数） → 住戸の特定（階・面積±0.5㎡・間取り・向き） → 金額（総額の差が数％以内） → **間取り図の pHash** → 元付業者 → 交通・設備の Jaccard
- 同じ建物の**別住戸**（同じ間取りが別の階にある）を誤って統合しやすい → 階と面積が一致しなければ別住戸として扱う

## 4. ヒアリングする項目と優先度
| 順 | 項目 | 優先度 | メモ |
|---|---|---|---|
| 1 | 入居時期 | must | 引越し理由で緊急度が決まる |
| 2 | 予算 | must | **総額か賃料だけか**を確認する。初期費用の上限も聞く |
| 3 | エリア・通勤先 | must | 駅名より「どこへ何分で行けるか」で聞く |
| 4 | 間取り・広さ | must寄り | 人数、在宅勤務の有無 |
| 5 | 入居条件 | must | ペット・楽器など。満たさないと契約できない |
| 6 | 駅徒歩 | want寄り | 「10分以内」が典型的な閾値 |
| 7 | 築年数・構造 | want | 「きれいならよい」という人が多い |
| 8 | 設備 | want | バス・トイレ別、室内洗濯機置場、独立洗面台、オートロック、2階以上 |

**条件を緩めるときの勘所**: 面積は−3〜5％（70㎡なら69.5㎡はほぼ問題なし）、賃料は+3〜5％、駅徒歩は+2〜3分、築年数は+5年が許容されやすい。
**緩和を提案する順**: 築年数 → 駅徒歩 → 設備 → 広さ → エリア → 予算。ポータルは賃料を5千円刻みで検索するので、**刻みの境界をわずかに超える物件は検索から漏れやすい** → Devoteが拾えば付加価値になる。

## 5. 類似物件（「これがハマるならこれもいい」）を特徴量にする
1. 同じ生活圏（通勤時間の等時間圏、並行する路線、隣の駅）
2. 価値の代替関係（新しさ ⇄ 駅近 ⇄ 広さ ⇄ 賃料）。ヘドニック回帰で**割安度**（予測賃料 − 実賃料）を出す
3. 建物のグレード（構造、総戸数、ブランドシリーズ、分譲賃貸かどうか）
4. 間取りの形（1LDK 40㎡ ⇄ 2DK 40㎡）
5. ユーザーの反応から推定する暗黙の嗜好
6. **客付のしやすさ**（広告可、AD付き、即入居可）→ 内見につながる確率
7. 説明文・画像の埋め込み（デザイナーズ等の雰囲気）

## 6. 情報ソース候補
| 区分 | ソース | 特徴 |
|---|---|---|
| 業者間 | レインズ（4機構） | 売買の網羅性が最も高い。会員限定 |
| 業者間（賃貸） | ATBB、ITANDI BB、いい生活スクエア、管理会社の業者向けポータル | **賃貸で最も鮮度が高い**。空室確認や内見予約までできるものが多い |
| ポータル | SUUMO、LIFULL HOME'S、at home、Yahoo!不動産、CHINTAI | 網羅性が高いが重複が多く、成約の反映が遅い |
| 自社サイト（賃貸） | いい部屋ネット、シャーメゾン、D-room、レオパレス21、へーベルメゾン、UR、JKK東京 | 自社サイトにしか出ない物件・自社サイトに先に出る物件がある |
| 自社サイト（売買） | 三井のリハウス、住友不動産販売、東急リバブル、野村の仲介+ | 専任物件を先に出す |
| 補助データ | 不動産情報ライブラリ（国交省）、レインズ・マーケット・インフォメーション、駅データ | 相場・割安度の計算に使う |

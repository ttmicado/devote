# 不動産ドメイン知識（Devote）

詳細なリファレンスは `docs/research/01-real-estate-domain.md` にある。作業前に該当章を読むこと。

## 必ず守るルール

- **金額は円・整数**、面積は㎡で持つ。「8.5万円」「1億2,980万円」は `parseYen`（`packages/core/src/normalize.ts`）で変換する
- **賃料の比較は管理費込みの総額**で行う（`price + managementFee`）。賃料・管理費・総額は分けて保持する
- **駅徒歩は道路距離80m=1分、端数切り上げ**（`walkMinutesFromMeters`）。バス便は `busMinutes` に分け、徒歩には混ぜない
- 築年月は和暦（平成/H、令和元年）を `YYYY-MM` に（`parseBuiltYearMonth`）
- 間取りは `1R/1K/1DK/1LDK/2SLDK` に正規化。「2LDK+S（納戸）」→ `2SLDK`、「ワンルーム」→ `1R`
- 設備・条件の自由記述はタグ化する（`packages/core/src/features.ts` の `FEATURE_DICTIONARY`）。新しい表記を見つけたら辞書にパターンを追加し、テストも足す
- 取引態様（貸主/代理/専任媒介/一般媒介/仲介）と**広告可否**は客付可否の判断材料なので、取れるソースでは必ず取る
- 入居条件（ペット・楽器・事務所・二人入居）は**hard条件**。満たさないと契約できない

## 用語の早見表

| 用語 | 意味 |
|---|---|
| 元付（物元） | オーナーから媒介・管理を受けた業者。広告可否・内見可否を決める |
| 客付 | 借主・買主を探して元付につなぐ仲介業者（Devote 側） |
| レインズ | 指定流通機構の業者間物件DB。会員（宅建業者）限定。売買の専任系は登録義務あり（専属専任5日・専任7日） |
| 業者間サイト | ATBB / ITANDI BB / いい生活スクエア。**賃貸の鮮度が最も高い** |
| マイソク | 販売図面。下部の「帯」に元付・広告可否・手数料配分 |
| AD | 賃貸の広告料（元付/オーナー→客付）。AD付き＝客付歓迎のシグナル |
| 囲い込み | 両手狙いで他社の客付を断る行為 → Devote では「対応不可」→ 類似提案 |
| 両手/片手 | 元付と客付が同一業者なら両手 |

## 条件緩和の勘所（AIヒアリング・スコアリングで使う）

- 面積 −3〜5%、賃料 +3〜5%、駅徒歩 +2〜3分、築年数 +5年は許容されやすい
- 緩和を提案する順: 築年数 → 駅徒歩 → 設備 → 広さ → エリア → 予算（予算と hard 条件は最後まで守る）
- ポータルは5千円刻みで検索されるため、刻みの境界をわずかに超える物件は検索から漏れやすい → Devote の差別化ポイント

## 同一物件の判定

ブロッキング: 都道府県・市区町村・町名・所在階・面積（0.5㎡丸め）・間取り・築年（`dedupeBlockKey`）。
同じ建物の別住戸（同じ間取りの別フロア）を誤って統合しないこと。階と面積が違えば別住戸。
